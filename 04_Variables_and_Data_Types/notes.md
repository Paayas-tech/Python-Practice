# Section 04: Variables & Data Types

* **Naming Convention:** Python uses snake_case (`my_variable_name`) for variables.
* **Dynamic Typing:** Variables don't have fixed types; they point to objects in memory. The type belongs to the object, not the variable.
* **`id()`:** Returns the unique memory address of an object.
* **`isinstance(obj, class)`:** Preferred way to check an object's type (e.g., `isinstance(x, int)` returns `True` or `False`).
