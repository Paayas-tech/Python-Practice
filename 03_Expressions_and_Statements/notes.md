# Section 03: Expressions vs. Statements

* **Expression:** Any piece of code that evaluates to a value (e.g., `5 + 3`, `len("abc")`, `x > 10`). Can be placed on the right side of an assignment `=`.
* **Statement (Instruction):** An instruction that performs an action or controls flow (e.g., assignment `=`, `if/else`, `import`, `def`, `return`). Statements cannot be printed or assigned directly.
